# D题识别

## 常见信号

- 有明确的物理、工程、生态、交通、传播或资源背景
- 给出过程规律、约束关系或机制信息
- 需要解释系统行为、预测变化或设计方案
- 常出现仿真、优化、概率、路径、调度等任务

## 优先检查

1. 是否存在可写出的机理关系？
2. 是否有守恒、几何、概率或工程约束？
3. 是否需要离散时间/空间仿真？
4. 是否需要寻找最优方案？
5. 是否存在不确定性和随机因素？

## 常见模型族

| 问题结构 | 候选模型 |
|---|---|
| 机理关系 | 微分方程、差分方程、守恒模型 |
| 概率风险 | 概率模型、蒙特卡洛、贝叶斯方法 |
| 资源分配 | 线性/整数/非线性规划 |
| 路径与网络 | 最短路、最大流、网络优化 |
| 调度 | 整数规划、启发式算法、遗传算法等 |
| 多因素影响 | 回归、敏感性分析、方差分析 |
| 动态传播 | 仿真、差分/微分方程、Agent-based等 |

## 模型升级原则

先建立能够解释题意的简单模型，再根据误差、规模或计算复杂度决定是否升级。
