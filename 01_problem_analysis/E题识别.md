# E题识别

## 常见信号

- 附件数据量较大
- 表格、时间序列、指标体系明显
- 需要发现规律、评价对象、预测结果或提出决策
- 数据清洗和特征处理本身就是重要工作

## 标准路线

**数据体检 → 探索性分析 → 特征/指标构造 → 基线模型 → 候选模型比较 → 预测/评价 → 决策优化 → 稳健性分析**

## 常见模型族

| 问题结构 | 候选模型 |
|---|---|
| 连续值预测 | 线性/岭/Lasso、随机森林、GBDT、XGBoost等 |
| 时间序列 | 移动平均、指数平滑、ARIMA、Prophet等 |
| 分类 | Logistic、树模型、SVM等 |
| 聚类 | K-means、层次聚类、DBSCAN等 |
| 综合评价 | 熵权、TOPSIS、主成分、因子分析等 |
| 变量筛选 | 相关分析、正则化、树模型重要性等 |
| 方案优化 | 线性/整数/非线性规划、启发式算法 |

## 重要约束

E题不能因为“有数据”就直接上机器学习。首先判断：

- 样本量是否足够？
- 变量是否存在明显共线性？
- 是否存在时间泄漏？
- 目标变量是否连续/分类？
- 是否需要解释变量影响？
- 是否有外推风险？
- 是否需要训练/验证/测试划分？

复杂模型必须和可解释基线模型进行比较。
