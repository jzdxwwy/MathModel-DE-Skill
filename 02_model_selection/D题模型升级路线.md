# D题模型升级路线

## 1. 默认原则

D题不是“模型越复杂越好”，而是“机理越清楚、约束越准确、结果越可验证越好”。

建议按以下层级升级：

> 解析/统计基线 → 经典数学模型 → 数值求解/仿真 → 优化 → 多目标/随机优化 → 数据驱动融合

只有前一级无法解决题目关键矛盾时才进入下一级。

## 2. 典型场景与模型

### 2.1 概率、误差与可靠性

- 正态/对数正态/Weibull等分布
- 蒙特卡洛模拟
- 可靠度与失效概率
- 贝叶斯更新（需要明确先验和数据）
- 置信区间与不确定性传播

**验证**：理论值与仿真值比较、样本量收敛性、参数敏感性。

### 2.2 资源配置与生产计划

- 线性规划 LP
- 整数规划 IP/MILP
- 非线性规划 NLP
- 多目标优化
- 鲁棒优化/情景优化

**验证**：可行性、约束满足、目标值、方案稳定性。

### 2.3 网络、路径与调度

- 最短路
- 最大流/最小割
- 多商品流
- 车辆路径问题 VRP
- 时间窗 VRPTW
- 整数规划
- 启发式/元启发式算法

**升级条件**：当精确算法出现组合爆炸时，才考虑遗传算法、模拟退火、禁忌搜索等，并用小规模精确解验证算法质量。

### 2.4 动力、传播、扩散

- 常微分方程 ODE
- 偏微分方程 PDE
- 元胞自动机
- Agent-based simulation
- 图网络传播模型
- 离散时间状态转移

**验证**：边界条件、守恒关系、极限情形、参数敏感性、仿真稳定性。

### 2.5 空间与几何

- 几何约束
- Voronoi/Delaunay
- 空间覆盖
- 布局优化
- Packing/覆盖问题
- GIS式距离/邻域分析

**验证**：面积/体积守恒、边界合法性、空间冲突检查。

## 3. D题四问式策略

面对每一问先回答：

1. **描述什么？**——建立指标、变量和状态。
2. **解释什么？**——寻找影响因素和机理关系。
3. **计算什么？**——估计概率、预测状态或求解参数。
4. **决策什么？**——给出最优方案、路径、资源配置或应急策略。

若后一问依赖前一问，应保存前一问输出，避免重新估计导致结果不一致。

## 4. 常见误区

- 一看到优化就直接遗传算法。
- 一看到预测就直接LSTM/Transformer。
- 一看到多指标就机械使用熵权-TOPSIS。
- 一看到随机性就只做蒙特卡洛而没有概率模型。
- 只给最优值，不检查约束是否满足。
- 只报告一次仿真结果，不报告随机误差或重复实验。
