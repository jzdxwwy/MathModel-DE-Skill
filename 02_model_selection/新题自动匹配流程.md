# 新题自动匹配流程

## 总流程

```text
题目文本 + 附件
      ↓
题型识别（D/E）
      ↓
任务类型抽取
      ↓
数据结构抽取
      ↓
约束与目标抽取
      ↓
历史 Benchmark 相似检索
      ↓
候选模型生成
      ↓
硬约束淘汰
      ↓
模型评分
      ↓
主模型 + 备选模型
```

## 1. 题型识别

不要只根据题号判断 D/E。结合：

- 题目对象
- 数据附件
- 问题结构
- 数学任务
- 决策变量
- 是否存在机理/随机性/时间结构

输出：

```text
contest_level: college
problem_type: D / E / uncertain
confidence: 0~1
reasons: [...]
```

## 2. 任务类型抽取

允许多标签：

- prediction
- evaluation
- optimization
- mechanism
- probability
- simulation
- time_series
- classification
- regression
- clustering
- network
- scheduling
- spatial
- multi_objective

## 3. 数据结构抽取

```text
cross_sectional
panel
longitudinal
time_series
spatial
network
experimental
mixed
```

## 4. Benchmark 检索

优先比较：

1. 数学结构；
2. 数据结构；
3. 目标结构；
4. 约束结构；
5. 决策结构；
6. 验证方式。

题目背景相似但数学结构不同，不应判为高相似。

## 5. 候选模型

每题至少给出：

- 主模型
- 简单基线
- 一个有意义的备选/升级模型

不得为了“高级”而强行加入复杂模型。

## 6. 输出模板

```text
题型：D/E
核心任务：...
数据结构：...
关键约束：...
最相似历史题：...
候选模型：
  A：...
  B：...
  C：...
主模型：...
备选模型：...
选择理由：...
验证方案：...
风险点：...
```

## 7. 特别规则

若识别结果不确定，必须显式标记 uncertain，不允许伪装成确定结论。
