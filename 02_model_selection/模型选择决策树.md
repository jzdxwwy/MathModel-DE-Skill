# 模型选择决策树

## 第一问：你到底要解决什么？

### A. 预测未来
优先考虑：基线统计模型 → 回归/时间序列 → 机器学习。

### B. 评价对象
优先考虑：指标体系 → 降维/赋权 → 综合评价 → 稳健性检验。

### C. 寻找最优方案
优先考虑：目标函数 → 约束 → 线性/整数/非线性规划 → 必要时启发式算法。

### D. 解释系统机制
优先考虑：机理模型 → 参数估计 → 仿真 → 敏感性分析。

### E. 研究随机风险
优先考虑：概率分布 → 参数估计 → 蒙特卡洛/随机模拟 → 风险指标。

### F. 网络/路径/调度
优先考虑：图模型 → 最短路/最大流/匹配 → 整数规划 → 启发式算法。

## 模型比较最低要求

候选模型不应只列名称。至少比较：

1. 与题意匹配度
2. 数据需求
3. 可解释性
4. 计算复杂度
5. 泛化能力
6. 验证难度
7. 对关键假设的敏感性

## 推荐原则

> 简单模型能解决，就不要为了“高级”而复杂化；简单模型解释不了，再升级。
