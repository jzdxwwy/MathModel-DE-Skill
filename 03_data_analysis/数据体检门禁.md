# 数据体检门禁

## 目标

任何 D/E 题进入建模前，先回答“数据是什么、能不能用、怎么用”。未经数据体检，不允许直接进入机器学习、优化或仿真。

## S1 文件与字段检查

- 列出全部文件、文件类型、大小、工作表。
- 识别字段名、单位、时间字段、ID 字段、目标变量。
- 检查合并键、重复键、时间粒度和空间粒度。
- 明确每一行代表什么：人、设备、车辆、路段、时刻、实验、订单等。

## S2 数据质量

至少检查：

- 缺失值：数量、比例、连续缺失区间。
- 重复值：完全重复和业务主键重复。
- 异常值：IQR、Z-score、业务阈值三类方法至少选一种。
- 单位：m/cm、秒/分钟、kg/t 等。
- 时间：时区、日期格式、排序、采样间隔。
- 类别：编码、拼写、稀有类别。

## S3 统计体检

输出：

- 描述统计
- 分布图/箱线图
- 相关矩阵
- 时间趋势（如适用）
- 分组统计
- 极端样本清单

不要只给图，要写出对建模有影响的发现。

## S4 泄漏检查

重点检查：

1. 目标变量的未来信息是否进入特征；
2. 同一个人/设备/车辆是否同时进入训练与验证；
3. 标准化、插补、特征选择是否使用了验证集信息；
4. 时间序列是否随机打乱；
5. 后验结果是否误当作输入变量。

## S5 建模前结论

必须形成 `data_audit.md`，至少包含：

```text
数据规模：
观测单位：
目标变量：
关键自变量：
缺失问题：
异常问题：
时间结构：
分组结构：
潜在泄漏：
可直接使用字段：
需处理字段：
不能使用字段：
推荐验证策略：
```

## 门禁规则

- 数据含义不清：暂停建模。
- 目标变量不明确：暂停监督学习。
- 时间结构明显：默认优先时间切分。
- 多记录属于同一对象：默认考虑 GroupKFold / 留一组验证。
- 存在未来信息：先修复特征，再训练模型。
- 单位不一致：先统一单位。
- 数据不足以支持复杂模型：退回简单模型。
