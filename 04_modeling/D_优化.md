# D题模型卡：优化

## 1. 什么时候用
出现“最小成本、最大收益、最优方案、资源配置、路径选择、调度、容量、预算、时间窗口”等词时考虑优化模型。

## 2. 标准形式
`min/max f(x)`

s.t.
`g_i(x) <= 0`
`h_j(x) = 0`
`x ∈ X`

## 3. 模型选择
- 线性目标 + 线性约束：LP；
- 0/1决策：MILP；
- 非线性但可微：NLP；
- 多目标：加权和、ε-约束、Pareto前沿；
- 随机参数：情景优化、鲁棒优化、随机规划。

## 4. 比赛中的升级原则
先把现实问题简化成“决策变量—目标—约束”，再选求解器。不要一开始就上复杂智能优化算法。

如果采用遗传算法、粒子群、模拟退火等启发式算法，必须与一个可解释基线或其他求解方法比较，并报告重复运行稳定性。

## 5. 必做检查
- 每个决策变量有明确现实含义；
- 每个约束有现实来源；
- 最优解满足全部约束；
- 目标函数回代正确；
- 对关键参数做敏感性分析；
- 若有多目标，解释权衡而不是只报一个“最优值”。

## 6. 常见坑
- 约束写漏；
- 单位混乱；
- 把连续变量强行四舍五入后破坏约束；
- 启发式算法一次运行就宣布最优；
- 多目标权重完全拍脑袋且不做敏感性分析。
