# D题模型卡：动态传播与扩散

## 1. 什么时候用
状态随时间变化，并且存在传播、扩散、增长、衰减、迁移、感染、污染、水流、热量或风险蔓延时使用。

## 2. 三层建模
### 层1：状态变量
定义 `x_i(t)`，明确每个变量的物理含义和单位。

### 层2：演化方程
常见形式：
`dx/dt = F(x,t;θ)`

离散形式：
`x(t+Δt) = F(x(t), θ, Δt)`。

### 层3：决策耦合
将动态状态转化为风险区域、可行域、路径或调度约束，再进入优化模型。

## 3. 选择方法
- 简单机理：ODE；
- 空间离散明显：有限差分/有限元思想；
- 网络传播：图上的状态转移；
- 规则复杂：离散事件仿真/Agent-based simulation；
- 数据充足：机理模型 + 数据校准。

## 4. 数值稳定性
改变时间步长 `Δt`，观察核心结论是否稳定；必要时比较不同积分方法。

## 5. 参数校准
参数必须有来源：附件数据、文献、规范、题目给定或明确的拟合过程。禁止为了让结果“好看”反推参数。

## 6. 典型组合
动态传播问题通常不是“一个模型解决四问”，而是：
**状态演化 → 风险判定 → 网络/空间可行域 → 优化决策 → 敏感性分析**。
