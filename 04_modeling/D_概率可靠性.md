# D题模型卡：概率与可靠性

## 1. 什么时候用
题目出现“命中概率、失效概率、可靠度、成功率、随机误差、重复试验、风险概率、不确定参数”等信号时优先考虑。

## 2. 基本建模
设事件成功概率为 `p`，独立重复 `n` 次，则成功次数 `X` 可建模为

`X ~ Binomial(n, p)`

若每次成功/失败概率不同，则不要强行使用二项分布，应使用独立非同分布模型或直接按试验过程计算。

可靠度常写为

`R = P(系统在规定条件和时间内完成规定功能)`

串联系统常见形式：`R = ∏ Ri`；并联系统常见形式：`R = 1 - ∏(1-Ri)`，但必须检查系统结构和独立性假设。

## 3. D题常见升级
- 随机误差 → 概率分布 + 数值积分/蒙特卡洛
- 参数不确定 → 参数分布 + 敏感性分析
- 多阶段过程 → 条件概率/状态转移
- 系统可靠性 → 结构函数/故障树思想
- 概率与决策耦合 → 期望收益/风险约束优化

## 4. Python最小模板
```python
import numpy as np

rng = np.random.default_rng(2026)
n = 100_000
p = 0.8
samples = rng.binomial(1, p, size=n)
estimate = samples.mean()
se = np.sqrt(estimate * (1 - estimate) / n)
print({'estimate': estimate, 'se': se})
```

## 5. 必须验证
- 样本量增加后估计是否稳定；
- 改变随机种子后结论是否稳定；
- 参数变化是否符合工程直觉；
- 若存在理论解，与数值解交叉验证。

## 6. 常见坑
- 把“概率估计”写成确定性结论；
- 忽略样本之间相关性；
- 未说明分布来源；
- 用一次模拟结果替代重复试验；
- 用拟合优度漂亮的分布掩盖数据量不足。

## 7. 论文表达
建议写成：**随机变量定义 → 分布/假设 → 概率表达式 → 参数估计 → 数值求解 → 稳健性验证 → 工程解释**。
