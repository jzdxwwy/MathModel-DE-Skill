# D题模型卡：蒙特卡洛模拟

## 1. 什么时候用
解析积分、复杂几何概率、随机过程、风险传播或约束复杂导致难以直接求解时使用。

## 2. 标准流程
1. 明确随机变量与分布；
2. 生成随机样本；
3. 计算每个样本对应的目标量；
4. 统计均值、概率、分位数或置信区间；
5. 增加重复次数并检查收敛；
6. 做参数敏感性分析。

## 3. 通用数学形式
若 `Y = g(X)`，则

`E[Y] ≈ (1/N) Σ g(X_i)`。

事件概率可写为

`P(A) ≈ (1/N) Σ I(X_i ∈ A)`。

## 4. Python模板
```python
import numpy as np

rng = np.random.default_rng(2026)
N = 200_000
x = rng.normal(0, 1, N)
y = np.exp(-x**2 / 2)
value = y.mean()
se = y.std(ddof=1) / np.sqrt(N)
print(value, se)
```

## 5. 验证门槛
至少做：
- `N` 梯度测试，例如 `1e4/5e4/2e5`；
- 2~5 个随机种子重复；
- 关键参数扰动；
- 若存在解析或高精度数值解，进行交叉验证。

## 6. 常见坑
- 把随机模拟当作唯一证明；
- 模拟次数过少；
- 随机种子未记录；
- 极小概率事件直接暴力抽样导致估计效率极低；
- 忽略输入变量之间的相关结构。

## 7. D题适配
2024D这类随机误差/命中概率问题尤其适合“概率模型 + Monte Carlo + 敏感性分析”的组合，但应先建立理论表达，再用模拟验证，而不是只给模拟图。
