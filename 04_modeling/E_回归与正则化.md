# E题模型卡：回归与正则化

## 1. 什么时候用
目标变量是连续数值，问题核心是“预测、解释因素影响、建立经验关系”时优先考虑。

## 2. 基线
线性回归：`y = β0 + β1x1 + ... + βpxp + ε`

若变量尺度差异大，先标准化；若存在明显非线性，再考虑多项式、树模型或其他非线性模型。

## 3. 正则化
岭回归：
`min ||y-Xβ||² + λ||β||²`

Lasso：
`min ||y-Xβ||² + λ||β||₁`

用于缓解多重共线性或控制过拟合。

## 4. 模型比较
至少比较一个可解释基线和一个增强模型，例如：
- Linear/Ridge；
- Random Forest；
- Gradient Boosting/XGBoost（环境允许时）。

指标根据任务选择 RMSE、MAE、R² 等，不能只看训练集。

## 5. E题特别注意
- 随机划分前先判断是否有时间结构；
- 同一个人、设备、地区等重复样本不能随意跨训练/测试；
- 特征工程不能使用未来信息；
- 外推区间必须单独说明。

## 6. 解释
重要特征可用标准化系数、Permutation Importance、SHAP等方法解释，但解释工具不能替代模型验证。
