# E题模型卡：时间序列

## 1. 什么时候用
数据带有明确时间顺序，并要求预测未来、分析趋势、周期、波动或预警时使用。

## 2. 基线优先
先做 Naive/Seasonal Naive，再考虑：
- 移动平均/指数平滑；
- ARIMA/SARIMA；
- 回归 + 时间特征；
- 树模型/机器学习；
- 多变量时序模型。

## 3. 正确验证
不能随机打乱时间序列。优先采用 rolling/expanding window 或 `TimeSeriesSplit`。

例如：
```text
训练 1 → 验证 1
训练 1+2 → 验证 2
训练 1+2+3 → 验证 3
```

## 4. 预测区间
除了点预测，条件允许时给出预测区间或误差区间，并说明不确定性来源。

## 5. 常见坑
- 用未来数据填补过去缺失值；
- 随机划分造成信息泄漏；
- 只看一次测试集；
- 把趋势拟合当成预测能力；
- 忽略结构突变。

## 6. 论文结构
**时序特征 → 基线 → 候选模型 → 时间交叉验证 → 指标比较 → 残差诊断 → 预测 → 稳健性分析**。
