# E题模型卡：综合评价

## 1. 什么时候用
题目要求对多个对象、方案、地区、产品或指标进行综合评分、排序、分级或优选时使用。

## 2. 标准流程
指标定义 → 正负向处理 → 无量纲化 → 权重确定 → 综合得分 → 排名/分级 → 稳健性分析。

## 3. 常用方法
- 熵权法：客观权重；
- AHP：专家偏好；
- CRITIC：结合变异性与冲突性；
- TOPSIS：评价对象与理想解的距离。

## 4. 权重不能只给一个答案
若权重主观性较强，应做权重扰动。例如将核心权重上下调整5%~20%，检查排名是否发生大范围变化。

## 5. TOPSIS基本思想
构造正理想解 `Z+` 与负理想解 `Z-`，计算对象到两者的距离 `D+`、`D-`，再定义贴近度：

`C_i = D_i^- / (D_i^+ + D_i^-)`。

## 6. 常见坑
- 正负指标方向处理错误；
- 权重与标准化重复放大某指标；
- 排名差异极小却下强结论；
- 忽略权重敏感性；
- 将综合评价结果误写成因果关系。
