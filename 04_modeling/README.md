# 04_modeling：D/E 算法建模库

本目录把“模型选择”进一步落到可执行层：不是只告诉模型叫什么，而是回答 **什么时候用、怎么建、怎么求、怎么验、什么时候不能用**。

## 使用顺序

1. 先完成 `01_problem_analysis/`：明确题型与子问题。
2. 再用 `02_model_selection/`：筛选候选模型。
3. 进入本目录：读取对应模型卡。
4. 用 `05_python/templates/` 的模板快速实现。
5. 用 `08_verification/` 做数据、模型、结果和论文追溯。

## 强制规则

- **基线优先**：先建立一个可解释、可验证的基线模型。
- **升级有理由**：复杂模型必须说明它解决了基线模型的什么不足。
- **结果可追溯**：论文中的数字必须来自实际运行结果。
- **模型必须验证**：至少报告误差、稳定性、敏感性或可行性中的一种；关键结论尽量使用两种以上验证。
- **不伪造数据**：没有附件、没有运行、没有验证，就不能声称得到了具体数值结论。
