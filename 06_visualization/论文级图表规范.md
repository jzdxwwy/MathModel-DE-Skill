# 论文级图表规范

## 核心原则

图不是装饰，而是回答问题的证据。每张图必须能够回答一个明确的问题。

## 图表类型选择

| 目的 | 推荐图 | 禁忌 |
|---|---|---|
| 看分布 | 直方图/箱线图 | 只报均值 |
| 看变量关系 | 散点+拟合 | 只画相关系数 |
| 看时间变化 | 折线/滚动统计 | 随机打乱时间 |
| 看空间/网络 | 热力图/网络图 | 无数据支撑的示意图冒充结果 |
| 比较模型 | 指标对比图 | 只展示最佳模型 |
| 看敏感性 | tornado/曲线 | 只口头说“影响很大” |
| 看优化方案 | 前后对比/ Pareto | 只给最优数字 |
| 看预测 | 真实值-预测值 | 只画预测曲线 |

## 每张结果图必须记录

- 数据来源
- 代码文件
- 运行参数
- 随机种子（如有）
- 横纵轴及单位
- 图中结论
- 是否用于论文

## E题特别要求

时间序列图必须保留时间顺序；模型比较至少包含一个简单 baseline。分类问题优先展示混淆矩阵、ROC/PR 或类别级指标；回归问题至少展示误差指标和残差诊断。

## D题特别要求

机理/仿真模型至少提供一个能解释模型行为的图；优化问题展示约束、目标值或方案变化；随机模型报告置信区间或重复试验稳定性。

## 论文交付

图表必须由真实运行结果生成。不得使用 AI 生成的虚假数据图，不得手工修改数据图中的数字。
