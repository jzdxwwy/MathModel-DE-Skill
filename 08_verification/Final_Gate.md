# Final Gate：数学建模最终质量门禁

提交论文前必须逐项通过。

## A. 数据真实性

- [ ] 所有数字均来自题目数据、公开来源或真实计算。
- [ ] 没有为了让结果更漂亮而修改原始数据。
- [ ] 数据清洗规则可解释、可复现。

## B. 模型一致性

- [ ] 符号定义完整。
- [ ] 单位一致。
- [ ] 假设与题意不冲突。
- [ ] 约束条件没有遗漏。
- [ ] 每个主要结论都能追溯到模型或计算。

## C. 计算正确性

- [ ] 核心公式经过独立检查。
- [ ] 关键数值至少有一种独立验证方式。
- [ ] 优化结果检查可行性。
- [ ] 仿真检查随机种子、重复次数和稳定性。
- [ ] 预测模型使用正确的训练/验证划分。

## D. 数据泄漏

- [ ] 无目标泄漏。
- [ ] 无未来信息泄漏。
- [ ] 无同一对象跨训练/验证泄漏。
- [ ] 预处理没有提前看到验证集/测试集。

## E. 图表

- [ ] 每张图均来自真实计算结果。
- [ ] 坐标轴、单位、图例完整。
- [ ] 图表结论与正文一致。
- [ ] 没有用示意图冒充计算结果。

## F. 稳健性

至少选择一项：

- 参数敏感性
- Bootstrap
- Monte Carlo
- 情景分析
- 留一组验证
- 时间滚动验证
- 扰动分析

必须说明结果是否稳定，以及哪些参数最敏感。

## G. 论文

- [ ] 每一问都有明确回答。
- [ ] 模型不是只写公式而没有解释。
- [ ] 结果不是只报数字而没有含义。
- [ ] 优点、缺点和改进方向真实存在。
- [ ] 参考文献与引用对应。
- [ ] AI 使用情况按当年竞赛规定如实披露。

## H. 最终输出

建议形成：

```text
paper/
├── main.pdf
├── figures/
└── Details of AI Tool Usage.pdf   # 当年规则要求时

results/
├── result_table.xlsx
├── key_results.csv
└── verification_summary.md

code/
└── 可运行源代码
```

## 红线

出现以下任一情况，禁止标记为“完成”：

1. 编造实验结果；
2. 编造参数；
3. 图表与代码不一致；
4. 无法解释核心结果；
5. 存在明显数据泄漏；
6. 论文声称完成但代码不能复现核心结果；
7. 未按当年竞赛 AI 规定披露 AI 使用。
