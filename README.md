# MathModel-DE-Skill

> 面向全国大学生数学建模竞赛 D、E 题的专用 Skill。

## 这个项目解决什么问题？

D/E题经常同时涉及数据分析、统计建模、优化、预测、仿真和机器学习。真正困难的不是“知道多少模型”，而是判断**什么时候该用什么模型，以及为什么**。

本 Skill 的目标是建立一套可复用的 D/E 专用工作流：

**题目识别 → 数据体检 → 历题相似检索 → 候选模型 → 模型比较 → 求解 → 验证 → 可视化 → 论文**

## 重点方向

### D题
机理建模、概率统计、仿真、优化、网络与路径、多目标优化、敏感性和稳健性分析。

### E题
数据清洗、探索性分析、特征工程、预测、回归、分类、聚类、综合评价、机器学习和决策优化。

## 设计原则

- 不迷信复杂算法
- 不虚构数据和结果
- 优先可解释基线模型
- 复杂模型必须说明升级理由
- 所有结论可追溯
- 所有图表来自真实计算
- 结果必须经过合理性与稳健性检查

## 计划中的竞赛知识库

重点整理 2021—2025 年 D/E 题，并优先建设 2024D、2024E、2025D、2025E benchmark。

知识库不以简单收集论文为目标，而是提取：

- 题目结构
- 子问题类型
- 数据结构
- 常见模型
- 模型选择依据
- 优缺点
- 可复用 Python 方法
- 验证方式
- 论文写法

## 使用方式

适用于支持 Skill / Agent 工作流的编码环境。将本仓库作为数学建模专用 Skill 后，可针对 D/E 题要求 Agent 按 `SKILL.md` 的约束完成建模、计算、验证和论文素材整理。
