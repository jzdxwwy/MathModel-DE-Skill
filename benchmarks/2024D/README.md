# 2024D：反潜航空深弹命中概率问题

## 1. Benchmark定位

这是一个典型的“随机误差 + 命中概率 + 空间几何 + 方案优化”D题案例。

2024年全国大学生数学建模竞赛官方资料将D题确定为“反潜航空深弹命中概率问题”，并提供了后续赛题解析与讲评。citeturn0search0turn0search24

## 2. 题型标签

`概率模型` `随机误差` `空间几何` `命中概率` `布置优化` `蒙特卡洛` `敏感性分析`

## 3. 建模主线

建议采用：

> 误差变量定义 → 概率分布假设/参数估计 → 单枚深弹命中概率 → 多枚深弹联合命中概率 → 投弹区域/数量方案优化 → 仿真验证 → 敏感性与稳健性

## 4. 候选模型

### 基线模型

用解析概率计算建立最基本的命中概率公式。

优点：解释性强、计算快、适合作为后续仿真的校验基准。

### 几何概率模型

将目标区域、误差区域和命中判据统一为空间几何关系，计算交集概率。

### 蒙特卡洛模型

当解析积分复杂、变量相关或投弹规则复杂时，用随机抽样估计命中概率。

必须报告：

- 随机种子（如需要复现）
- 模拟次数
- 估计值
- Monte Carlo标准误差/置信区间
- 收敛性检查

### 优化模型

如果题目要求在投弹数量、位置、间距等条件下提高总体命中率，可建立：

- 决策变量：投弹位置、投弹数量、间距等
- 目标：最大化总体命中概率
- 约束：投弹数量、区域边界、间距、安全条件等

## 5. 模型选择规则

不要默认使用遗传算法。

如果决策变量少、目标函数可计算且约束简单，优先解析/枚举/网格搜索；只有当组合规模明显扩大、目标函数非凸或解析方法难以处理时，再考虑启发式优化。

## 6. 必做验证

1. 极端情况下概率是否趋近合理边界。
2. 投弹数量增加是否符合概率规律。
3. 误差标准差增大时命中概率是否合理变化。
4. 解析结果与蒙特卡洛结果是否一致。
5. 最优方案改变参数后是否仍然稳定。

## 7. 论文输出建议

论文中应把“概率模型”和“方案优化”分开写清楚：

- 模型假设
- 随机变量定义
- 命中判据
- 概率公式
- 参数估计
- 优化模型
- 求解算法
- 仿真验证
- 敏感性分析
- 最终方案
