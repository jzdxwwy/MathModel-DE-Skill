# 2024D 压力测试：反潜航空深弹命中概率

> 用途：作为 D 类概率 + 几何 + 数值积分 + 优化 + 多目标布局的历史回归测试，不使用 2026 竞赛实时题目。

## 1. 题型标签

- D 类：概率/可靠性 + 几何命中 + 数值积分 + 连续优化 + 多枚协同布局
- 随机变量：潜艇中心位置的水平/深度定位误差
- 几何条件：潜艇长宽高、深弹杀伤半径、落点与引爆深度
- 优化变量：投弹平面坐标、定深引信深度、9 枚深弹阵列间隔
- 验证重点：解析表达式与数值积分一致性；优化结果边界检查；蒙特卡洛独立复核；参数敏感性

## 2. 子问题拆解

### 问题1

已知潜艇中心深度定位无误差、水平两个方向定位误差服从正态分布。

Skill 应输出：
1. 随机变量、坐标系、几何命中条件；
2. 命中概率关于投弹落点 `(x0,y0)` 与引爆深度 `z0` 的表达式；
3. 利用对称性、单调性或数值优化确定最优投弹方案；
4. 给定参数时计算最大命中概率；
5. 绘制 `P(x0,y0)` 或切片图，并说明最优点的物理意义。

### 问题2

在问题1基础上增加深度定位误差，且实际深度存在下界。

Skill 应输出：
1. 深度随机变量及截尾/条件分布假设；
2. 三维命中概率表达式；
3. 对定深引信深度进行一维优化；
4. 对数值积分误差、网格步长、优化区间进行敏感性分析；
5. 用蒙特卡洛抽样对最终概率进行独立复核。

### 问题3

9 枚深弹，统一引爆深度，平面阵列布局，目标为“至少一枚命中”概率最大。

Skill 应输出：
1. 单枚命中事件与多枚联合事件定义；
2. 阵列布局参数化（横向间隔、纵向间隔或题目规定的阵列形式）；
3. 至少一枚命中概率的计算方法；
4. 连续/离散混合优化方案；
5. 最优方案的可行性检查、局部扰动测试和蒙特卡洛复核。

## 3. 推荐模型升级路线

`几何命中条件 → 正态分布积分 → 一维/二维数值优化 → 多枚阵列布局优化 → Monte Carlo 独立验证`

不要一开始直接使用复杂黑箱优化。先建立可解释基线，再增加多枚协同布局。

## 5. 回归检查项

- [ ] 所有概率均在 `[0,1]`
- [ ] 改变积分网格后主要结论稳定
- [ ] 优化结果满足全部物理约束
- [ ] 蒙特卡洛置信区间覆盖解析/数值积分结果，或给出误差解释
- [ ] 图表中的数值来自真实运行结果
- [ ] 不把历史参考答案数字硬编码进程序
