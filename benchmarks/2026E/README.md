# 2026E：SEM 广告投放策略

> Benchmark ID `CUMCM-2026E`　类型 E（数据类）　状态 **B01_INPUT_READINESS = READY（尚未求解）**

## 1. 题目

2026 年高教社杯全国大学生数学建模竞赛 E 题。某互联网公司针对某产品投放 SEM 广告，
共设计 5 个方案、12 个推广单元、6000 余个关键词，2025 年投入资金约 142 万元，
希望通过优化关键词和相应的投放策略进一步提高广告投放效益。

## 2. 子问题（依据题目原文提炼，非引自任何参考解）

1. **策略合理性诊断**：依据附件 1 的 2025 年数据，从广告设计质量与创意、关键词管理与运用、
   出价策略与预算、投放策略与时间四个方面分析投放策略合理性，并分析投放效益随时间的变化规律和假日效应。
2. **关键词五分类**：按投入成本与效益分为黄金词（低成本高效益）、重点词（高成本高效益）、
   潜力词（低成本低效益）、问题词（高成本低效益）、无效词（无成本无效益）。结果写入 `result2.xlsx`。
3. **确定性预算下的逐日投放优化**：在保证各推广单元低成本、高效益、完成但不超过预算的条件下选择关键词，
   给出 2025-02-01～02-08 与 2025-08-01～08-08 每天的最优投放策略。结果写入 `result3.xlsx`。
4. **不确定性下的稳健投放预测**：2026 年沿用 2025 年的方案、推广单元与关键词，预算不超过 2025 年投入；
   考虑每个关键词竞价每日变化以及展现量、展现位、点击量、浏览量、注册量的不确定性，
   给出 2026-09-11～09-17 每天的最优投放策略并估计各指标的期望范围。结果写入 `result4.xlsx`。
