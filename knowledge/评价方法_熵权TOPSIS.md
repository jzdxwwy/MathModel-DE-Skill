# 综合评价：熵权法 + TOPSIS

> 适用题型：E 题常见的"从若干方面评价/排序若干对象"的评价类子问题。
> 本项目实现：`05_python/templates/entropy_topsis.py`，模型族 `entropy_topsis`。

## 1. 什么时候用

- 有**多个可比较的对象**（方案、推广单元、关键词分组、地区……）；
- 每个对象有**多个可以量化的指标**；
- 题目要求给出**合理性评价、优劣排序或权重**，而不是预测某个未来数值。

不适合：只有一个对象、指标无法量化、或题目真正问的是预测/优化。

## 2. 方法步骤

### 2.1 构造决策矩阵

把"对象 × 指标"整理成矩阵 `X`，`x_ij` 表示第 i 个对象在第 j 个指标上的取值。

**本项目要求比率型指标先聚合再相除**：

```
CTR = Σ点击量 / Σ展现量        ✓ 正确
CTR = mean(每日点击量 / 每日展现量)   ✗ 错误
```

后者会被展现量极小的那些天主导，是对数据的隐性加权。模板因此先按对象聚合源列，
再由聚合后的列构造比率。

### 2.2 指标方向

每个指标必须显式声明方向，**不从列名推断**：

- `+` 越大越好（CTR、占比、收益……）
- `-` 越小越好（成本、CPC、误差……）

方向搞反会让排序整体失真，而且不会报错——这是最容易犯且最难发现的错误。

### 2.3 极差归一化并统一方向

对每个指标：

```
效益型（+）：y = (x - min) / (max - min)
成本型（-）：y = 1 - (x - min) / (max - min)
```

归一化后所有指标都变成"越大越好"，量纲被消除。

### 2.4 熵权

```
p_ij = y_ij / Σ_i y_ij
e_j  = -k Σ_i p_ij ln p_ij,   k = 1 / ln(m)
d_j  = 1 - e_j                （差异系数）
w_j  = d_j / Σ_j d_j
```

含义：**某个指标在各对象之间差异越大，说明它区分能力越强，权重越高**；
如果所有对象在该指标上取值相同（方差为 0），它没有任何区分能力，权重为 0。

### 2.5 TOPSIS 排序

```
v_ij = w_j · y_ij
正理想解 v+ = 每列最大值
负理想解 v- = 每列最小值
D+_i = sqrt(Σ_j (v_ij - v+_j)²)
D-_i = sqrt(Σ_j (v_ij - v-_j)²)
贴近度 C_i = D-_i / (D+_i + D-_i)
```

`C_i` 越大越优，按 `C_i` 降序排名。

## 3. 必须说清楚的局限

1. **权重来自数据，不表达偏好**。熵权法只反映"哪个指标区分度高"，
   不代表"哪个指标更重要"。题目若给出主观权重或要求 AHP，熵权法不能替代。
2. **权重依赖归一化方式**。极差归一化后各列跨度都被拉到 [0,1]，
   熵权衡量的是分布形状而不是原始量级。换一种归一化会得到不同的权重——
   所以归一化方式必须写进论文，不能只报权重数字。
3. **对象数量少时不稳定**。接近 10 个对象以下时，个别极端值会显著改变权重；
   应同时报告权重对样本的敏感性。
4. **零方差指标权重为 0**。本模板会把它列进 `zero_variance_indicators` 并记入 manifest。
   若所有指标方差都为 0，模板直接失败，而不是给出一份无意义的排名。
5. **贴近度是相对量**。`C` 只在本次比较的对象集合内有意义，
   不能跨批次比较，也不能解释成"得分 0.15 就是差"。
6. **指标选择本身就是建模决策**。方法不会替你判断"广告设计质量"该用哪个字段衡量。
   这一步必须在论文里给出理由并接受质疑。

## 4. 本项目实现的契约

模板通过模块属性接收配置（由 `tools/runtime/template_adapter.py` 注入）：

| 属性 | 含义 |
| --- | --- |
| `DATA_PATH` | 输入 CSV（由 adapter 从 xlsx 指定 sheet 转换而来） |
| `ENTITY_COL` | 被评价对象的列名 |
| `INDICATORS` | `[{"name", "direction", "ratio"?}]`，`ratio` 为 `[分子列, 分母列]` |
| `AGGREGATE` | `mean` / `sum` / `last`，按对象聚合源列的方式 |

产物：

- `results/entropy_topsis_scores.csv`：每个对象的 `closeness`、`d_plus`、`d_minus`、`rank` 及原始指标
- `results/entropy_topsis_weights.csv`：每个指标的熵值、差异系数权重与方向
- `results/entropy_topsis_manifest.json`：输入哈希、指标定义、权重、零方差指标、运行参数

因为指标定义、方向与权重全部进入 manifest，论文里的每个排名数字都能沿
`排名 → scores.csv → 指标定义 → 原始附件` 回溯。

## 5. 与相邻方法的取舍

| 方法 | 何时优先 |
| --- | --- |
| 熵权法 / TOPSIS | 需要客观权重 + 多对象排序，指标可量化 |
| AHP | 指标难以量化，或题目本身要求层次分析（主观判断必须来自专家/题面） |
| 灰色关联 | 样本量很小、信息不完全 |
| 主成分分析 | 指标高度相关，需要先降维再评价 |

可解释性优先：能用熵权-TOPSIS 讲清楚，就不要为了"高级"上神经网络。
