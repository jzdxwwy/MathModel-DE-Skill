# Stage 00 — Start Skill

## 目的
建立一次数学建模项目的初始状态，并输出 `ProblemSpec`。

## 输入
- 题目文本
- 用户要求
- 题目附件

## 必须完成
1. 判断 Skill Development / Benchmark / Problem Solving 模式；
2. 登记题目与附件来源；
3. 提取背景、问题、显式要求；
4. 区分已知事实、待确认信息和推断；
5. 建立 question_id；
6. 创建项目计划与 todo。

## 输出
- `ProblemSpec`
- project plan
- todo

## Gate
不得把未读取或未确认的信息写成题目事实。
