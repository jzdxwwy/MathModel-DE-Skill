# Stage 01 — Analysis Skill

## 目的
把 `ProblemSpec` 转换为可建模的问题结构 `ProblemMap`。

## 核心任务
- 子问题拆解
- task_type 识别
- 变量、输入、输出定义
- 约束与依赖关系
- 候选方法族

## task_type
prediction / evaluation / optimization / classification / clustering / simulation / mechanism / network / risk / comprehensive_decision

## 输出
- `ProblemMap`

## Gate
不能因为 D/E 标签直接决定模型；必须先说明问题任务结构。
