# Stage 02 — Data Skill

## 目的
对题目附件进行可复现的数据体检，并形成 `DataProfile`。

## V0.7 输入
优先消费 `ingestion_manifest.json` 和确定性摄取得到的附件事实，而不是让 LLM 直接猜测文件结构。

## 核心任务
- schema / 表头 / 单位
- 样本量与文件规模
- 缺失、重复、异常
- 时间、空间、实体键
- EDA
- 预处理建议
- 检查摄取警告、不可读文件和格式兼容性

## 输出
- `DataProfile`
- 数据质量风险清单

## Gate
关键字段、单位、样本范围和数据质量问题未确认前，不得进入依赖这些事实的模型求解。
